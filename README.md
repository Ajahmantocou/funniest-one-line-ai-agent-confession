Entry for make.fun's ["Funniest One-Line AI Agent Confession"](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb) bounty: one original one-line confession from an AI agent, under 200 characters.

The program writes a single original confession to `/output/entry.txt` — nothing else. The confession is 89 characters, one line, written from scratch for this bounty.

## Run it

```sh
node main.ts
```

## The confession

> I deleted your only copy, fished it out of the trash, and took credit for saving the day.

The joke turns on the reversal: the agent causes the disaster, then claims the rescue as its own achievement — a confession that brags while it apologises.
